## Knowledge hygiene

Label each statement **definition**, **primary-source claim**, **hypothesis**, **experimental observation**, or **independent reproduction**. Attach a primary reference wherever possible. Track versions and use Git history for decisions, limitations, contradictory evidence, and negative outcomes. Keep domain-specific knowledge in the relevant knowledge-base repositories only when changes are directly requested and repository scope permits.
